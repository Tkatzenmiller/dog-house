# Dawg Houses

Interactive map of Georgia Bulldogs football hometowns: players, coaches, NFL tracker, nearest-Dawg finder, decade tour, and a Guess the Dawg quiz. Everything is in `index.html`.

## Put it on Vercel (through GitHub)

1. Create a new repository at github.com/new.
2. Click **uploading an existing file** and drag in `index.html` and `README.md` (not the zip). Click **Commit changes**.
3. On vercel.com: **Add New → Project**, import the repository, leave Framework Preset on **Other**, and click **Deploy**.

No build step or API key is needed.
